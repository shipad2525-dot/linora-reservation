# Linora nail & care ― 予約管理システム（プロトタイプ）

## 構成
- `index.html` … お客様向け予約ページ（メニュー選択 → 日時選択 → 情報入力 → 確認・送信）
- `admin.html` … オーナー向け管理画面（予約一覧・確定/キャンセル操作、簡易パスワード保護）
- `shared.js` … メニューデータ・営業時間・予約データの読み書き

写真のメニュー表（NAIL CARE / GEL MENU / OPTION / OFF）の内容をそのまま反映しています。

## 今すぐ確認できること
`index.html` をブラウザで開くと、実際の予約フロー（メニュー選択→日時→お客様情報→確認→送信完了）を一通り試せます。送信した予約は `admin.html`（パスワード: `linora2026`）で確認・確定・キャンセルできます。同じブラウザ内であれば、送信した予約がそのまま管理画面に反映されます。

## ⚠️ 今の状態でURLを発行する前に知っておくこと
今のデータ保存はブラウザの localStorage です。これは「その端末・そのブラウザの中だけ」に保存される仕組みなので、**お客様がスマホで予約 → オーナーが別のスマホの管理画面を見ても、その予約が表示されません。** リンクを貼ってURLを発行するだけでは、お客様とオーナーの間で予約情報が共有されないため、実運用では使えません。

デザインや予約の流れ（画面遷移・入力項目）を確認したいだけであれば今のファイルのままでも十分ですが、実際にお客様に使ってもらうには「共有データベース」を足す作業が必須です。

## 次にやること（優先順） 
1. **Vercelアカウントを用意する**（無料）— https://vercel.com　とりごろ案件と同じホスティング先です。GitHubアカウントでログインできます。
2. **共有データベースを接続する** — Vercel KV（Vercelの中で使える無料枠のデータストア）を使い、予約データをお客様・オーナー間で共有できるようにします。この配線は次のステップで私が行います。
3. **デプロイしてURLを発行** — Vercelにアップロードすると `https://◯◯.vercel.app` のようなURLが自動で発行されます。このURLをLINEリッチメニューに貼り付ければ完了です。
4. **（任意・後回しでOK）LINE通知連携** — 予約が入った時にオーナーのLINEに自動通知したい場合は、LinoraさんのLINE公式アカウントのチャネルシークレット・アクセストークンが必要になります（LINE Developersでの登録）。今すぐ必須ではなく、まずは管理画面での確認だけでも運用は可能です。
5. **（任意）管理画面のパスワード強化** — 現在の簡易パスワード(`linora2026`)は開発用です。本番運用前に変更・強化します。
